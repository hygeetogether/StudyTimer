# 🚀 스터디 + 할 일 관리 타이머: 프로젝트 계획서

## 1. 프로젝트 개요

**프로젝트명**: 스터디 + 할 일 관리 타이머 (StudyTimerApp)

**목표**: 사용자가 학습, 업무 등 다양한 할 일을 등록하고, 각 항목에 타이머를 설정하여 집중력을 높이며 진행 상황을 시각적으로 추적할 수 있는 데스크톱 애플리케이션을 개발합니다.

## 2. 주요 기능

- **할 일(Task) 관리 (CRUD)**
  - **(C) 생성**: 사용자가 '할 일'의 이름과 '측정 시간(분)'을 입력하여 목록에 추가합니다.
  - **(R) 읽기**: 추가된 할 일 목록을 ListView에 표시합니다. (항목: 할 일, 설정 시간, 상태)
  - **(U) 수정**: 목록의 항목을 더블클릭하여 이름과 시간을 수정합니다.
  - **(D) 삭제**: 목록에서 선택한 할 일 항목을 제거합니다.

- **타이머 기능**
  - ListView에서 특정 할 일을 선택하고 '시작' 버튼 클릭 시 타이머가 작동합니다.
  - 타이머가 작동하는 동안 남은 시간을 `mm:ss` 형식으로 표시합니다.
  - 타이머 '일시정지' 및 '정지'(초기화) 기능을 제공합니다.

- **진행 상황 시각화**
  - 타이머 작동 시, ProgressBar를 통해 설정 시간 대비 현재 진행률을 실시간으로 표시합니다.
  - 타이머가 완료되면 작업 완료를 알리는 MessageBox를 표시합니다.

## 3. UI 설계 및 주요 컨트롤

메인 폼은 크게 3개의 영역으로 구성됩니다.

- **입력 패널 (`gbInput`)**
  - `lblTask`: "할 일:" 레이블
  - `txtTaskName`: 새로운 할 일 이름을 입력하는 텍스트 박스
  - `lblMinutes`: "시간 (분):" 레이블
  - `numMinutes`: 타이머 시간을 설정하는 NumericUpDown 컨트롤
  - `btnAddTask`: 입력된 작업을 목록에 추가하거나 수정하는 버튼

- **작업 목록 패널 (`gbTaskList`)**
  - `lvTasks`: 추가된 할 일 목록을 표시하는 ListView
    - **Columns**: "할 일", "설정 시간", "상태"
  - `btnDeleteTask`: ListView에서 선택된 항목을 삭제하는 버튼

- **타이머 패널 (`gbTimer`)**
  - `lblSelectedTask`: 현재 선택된 할 일의 이름을 표시하는 레이블
  - `lblTimerDisplay`: 남은 시간을 "00:00" 형식으로 표시하는 레이블
  - `pbProgress`: 타이머의 진행률을 표시하는 ProgressBar
  - `btnStartPause`: 타이머 시작/일시정지 토글 버튼
  - `btnStop`: 타이머 중지 및 초기화 버튼

## 4. 동작 과정 (사용 시나리오)

1. **애플리케이션 실행**: 프로그램을 시작하면 메인 폼이 나타납니다.

2. **새 작업 추가**:
   - 상단의 '새 작업 추가' 패널에서 '할 일' (예: "C# 공부")을 입력합니다.
   - '시간 (분)'을 원하는 시간(예: 50)으로 설정합니다.
   - '추가' 버튼을 클릭하면 '작업 목록'에 해당 항목이 "대기" 상태로 추가됩니다.

3. **작업 수정**:
   - '작업 목록'에서 수정하고 싶은 항목(예: "C# 공부")을 **더블클릭**합니다.
   - 상단의 '새 작업 추가' 패널에 해당 항목의 이름과 시간이 자동으로 입력되고, 버튼이 '수정'으로 변경됩니다.
   - 원하는 대로 이름이나 시간을 변경한 후 '수정' 버튼을 클릭하면 목록의 항목이 업데이트됩니다.

4. **타이머 시작**:
   - '작업 목록'에서 시작할 항목을 클릭하여 선택합니다.
   - 우측 '타이머' 패널의 '선택된 작업'이 표시되고, 타이머가 설정 시간으로 맞춰집니다.
   - '시작' 버튼을 누르면 타이머가 1초마다 감소하며, 하단의 ProgressBar가 채워지기 시작합니다. 작업 상태는 "진행중"으로 변경됩니다.

5. **타이머 제어**:
   - 타이머가 동작하는 동안 '일시정지' 버튼을 눌러 잠시 멈출 수 있습니다. 작업 상태는 "일시정지"가 됩니다.
   - 다시 '시작' 버튼을 누르면 타이머가 이어서 진행됩니다.
   - '정지' 버튼을 누르면 타이머가 설정 시간으로 초기화되고 ProgressBar도 리셋됩니다. 작업 상태는 "대기"로 돌아갑니다.

6. **타이머 완료**:
   - 타이머가 "00:00"에 도달하면, 작업 완료 알림창이 뜹니다.
   - 작업 상태는 "완료"로 변경됩니다.

7. **작업 삭제**:
   - '작업 목록'에서 삭제하고 싶은 항목을 선택합니다.
   - '선택 삭제' 버튼을 클릭하면 목록에서 해당 항목이 영구적으로 제거됩니다.

## 5. 개발 환경

- **IDE**: Visual Studio Community 2022
- **언어**: C#
- **프레임워크**: .NET Framework 4.7.2

## 6. 실행 방법

1. **프로젝트 클론**:
   ```bash
   git clone https://github.com/hygeetogether/StudyTimer.git
   ```
2. **Visual Studio에서 열기**:
   - `StudyTimer` 폴더로 이동하여 `StudyTimerApp.sln` 파일을 Visual Studio 2022로 엽니다.
3. **빌드 및 실행**:
   - Visual Studio 상단 메뉴에서 `빌드(Build) > 솔루션 빌드(Build Solution)`를 선택합니다.
   - `디버그(Debug) > 디버깅 시작(Start Debugging)` 또는 `F5` 키를 눌러 애플리케이션을 실행합니다.
