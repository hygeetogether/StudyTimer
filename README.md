# 스터디 + 할 일 관리 타이머 (Study + To-Do Management Timer)

## 프로젝트 소개

이 프로젝트는 사용자가 학습, 업무 등 다양한 할 일을 등록하고, 각 항목에 타이머를 설정하여 집중력을 높이며 진행 상황을 시각적으로 추적할 수 있도록 돕는 C# Windows Forms 기반의 데스크톱 애플리케이션입니다.

## 주요 기능

- **할 일(Task) 관리**: 할 일 추가, 삭제 기능 제공.
- **타이머 기능**: 선택된 할 일에 대한 타이머 시작, 일시정지, 중지 기능.
- **진행 상황 시각화**: ProgressBar를 통해 타이머 진행률 실시간 표시.
- **알림**: 타이머 완료 시 메시지 박스 알림.

## 개발 환경

- **IDE**: Visual Studio Community 2022
- **언어**: C#
- **프레임워크**: .NET Framework 4.7.2
- **유형**: Windows Forms 애플리케이션

## 실행 방법

1. **프로젝트 클론**: 
   ```bash
   git clone https://github.com/hygeetogether/StudyTimer.git
   ```
2. **Visual Studio에서 열기**: 
   `StudyTimer` 폴더로 이동하여 `StudyTimerApp.sln` 파일을 Visual Studio 2022로 엽니다.
3. **빌드 및 실행**: 
   Visual Studio에서 프로젝트를 빌드(Build)하고 실행(Start)합니다.

## 사용 방법

1. **새 작업 추가**: 상단의 "새 작업 추가" 그룹 박스에서 할 일 이름과 시간을 입력하고 "추가" 버튼을 클릭합니다.
2. **작업 선택**: "작업 목록"에서 시작할 할 일을 선택합니다.
3. **타이머 제어**: "타이머" 그룹 박스에서 "시작" 버튼을 클릭하여 타이머를 시작합니다. "일시정지" 또는 "정지" 버튼으로 타이머를 제어할 수 있습니다.
4. **작업 삭제**: "작업 목록"에서 삭제할 할 일을 선택하고 "선택 삭제" 버튼을 클릭합니다.
